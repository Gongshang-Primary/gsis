# GSiS v0.5.0

Authorized 2 October 2026, 23:06 Singapore. This release implements Q125–Q133. It is a committed installation package; live installation is separate.

- Info starts with **Workload**, then **Stats**, then **Ledger**. Workload explains the existing calculation in simpler language and uses ordinary supporting tables on one page. Stats contains the reference ranges, Max/Modal/Avg/Min and headcount; its numbers are centred. Neither page has column hiding or Excel controls. Ledger retains teacher assignments/status and its existing tools, with centred numeric cells, names aligned left/top and PD at the right.
- Fortnight numbers are centred and text aligned left. Switches update the existing row, keeping focus and scroll position. Fortnight and reporting-link saves use a settings projection instead of reconstructing assignments, venues, duties and history. The journal, receipts, optimistic conflicts and fresh authority checks remain in force.
- Span of Control uses bounded layers with blue horizontal scrollbars, compact name buttons and partial-name Unassigned search. Clicking a name retains keyboard-accessible RO selection. MK/OSO exclusions, four SL boxes, descendants, cycle guards and the viewing tree remain. Initializing its staff list now requests the authoritative Contacts staff data.
- Teachers Planner notes, Offload Notes and Version Notes are apparent, full-cell textboxes. Versions places Actions before a wider Notes column and retains per-row Save note.
- Both Layout exports retain all available records despite missing/duplicate venue IDs. Ambiguous records appear in the same workbook's appendix. Literal worksheet strings, blank numeric types, namespaces, row/cell order and dimensions are normalized. Save/publication validation remains unchanged.
- ISH east stair retains its location, with a clear ground doorway approach, one flat upper canopy and a direct top landing to the doorway. Other intermediate landings, the original viewer and the closed Showcase route remain.

Deploy write protocol is **500**. Install the matching frontend and backend together; older clients cannot write using stale projection metadata.

The separate current 2026 Contacts feed was re-read from its live sheet and matches the prior import. Its activation is still an installation step, not a new Deploy version or a workload import. See DEPLOYMENT.md.
