# GSiS Suite v0.9 source status

The reviewed GSiS optimisation and LORD integration drafts are included in the authorised v0.9 release. The earlier draft archives are historical snapshots, not the current installation package.

Use `README.md`, `CHANGELOG_v0.9.md`, `DEPLOYMENT.md` and `docs/GSiS-v0.9-Maintainer-Guide.md` for the current release. `VALIDATION.md` and the release notes record verification. The root release process records the commit and tag after its final checks.

The maintained `lord-suite` source contains placeholders for private instance configuration. Preserve existing IDs, secrets, booking peppers, transaction history and access settings in a private configured build before uploading it. Do not upload a source archive or outer suite ZIP directly to Pages.

The release contains eight frontend packages, five complete backend files and the Roster notification Worker. No live deployment, bridge activation, timetable publication or staff message is performed by source finalisation.
