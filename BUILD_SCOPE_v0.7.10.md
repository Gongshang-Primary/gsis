# v0.7.10 build scope

The user authorised the full versioned deployment package, Deploy manual update, Archify schema/workflow HTML, current-install and blank-install guidance, and a separate WhatsApp activation guide. The working baseline is the complete v0.7.09 source plus its previously prepared default-draft fix.

Ponytail, Pstack and both Thermonuclear review passes apply to the change. UI reviews use the requested design skills. Existing authority, stable identities, exact-retry receipts, expected revisions, protected assignments and durable notification claims remain the boundaries. No new database, external queue, persistent browser staff cache or production recipient allowlist is introduced.

The package implements the post-v0.7.09 queue recorded in PROJECT_RECONCILIATION_v0.7.10.md, with the explicitly open retroactive subject-policy decision documented separately. It does not reinterpret old log-only requests as permission to delete current school records.

Commit means a versioned deployable ZIP. The build does not create a Git commit, deploy production, publish a timetable, mutate live data or send messages. The activation guide supplies the concrete settings for both Cloudflare components. Runtime defaults remain disabled so installation and live activation remain distinguishable.
