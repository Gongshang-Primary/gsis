# v0.9.7 accepted scope

The user requested a full v0.9.7 release using Workers Paid, persistent compressed timetable caching with sensible R2 pruning, and Worker-owned Roster and Deploy reads/writes. Four additions were proposed and explicitly approved individually: administrator System Health, Queue-backed background work, recovery checkpoints with a safe operator procedure, and a private operational backend with service bindings.

The release also includes the previously requested completed-receipt dismissal/History controls and retains the v0.9.5a STAPLER teacher lookup changes (non-MK teachers, partial text search). v0.9.6's change-driven cron and bounded generated-cache cleanup remain the baseline.

Excluded from this local release operation: live Cloudflare deployment, resource migration, live restoration, production notification sends, medical absence creation, account transfer, new third-party integrations and changes to school access policy. Earlier requests in the project are context, not instructions to repeat those live actions.

Venues may receive the name of the person occupying a venue within its authorised occupancy projection. SMC drafts and private staff details remain excluded. Existing Google authorities and source/transaction fences must remain valid.

Source provenance: this worktree derives from the supplied v0.9.5 source, its locally verified v0.9.5a changes and corrected v0.9.6 packaging (7a8b2fb). It does not claim to reconstruct missing upstream historical Git tags. The complete source ZIP is the maintenance baseline.
