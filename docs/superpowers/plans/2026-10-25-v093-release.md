## Calendar cache contract

Worker may return `data.calendarCache` as an opaque signed envelope, retained per current account and returned as `input.calendarCache` by the browser. It contains only released school-day metadata for a bounded 62-day window, stable source revision, checked timestamp and actor/config binding. Fresh read reuse is bounded; expired data needs a current conditional Calendar revision check. Mutation routes never accept cached Calendar authority. Unavailable Calendar state cannot certify a usable day. Pending writes permit a fresh uncached read but never issue a reusable signed proof.
