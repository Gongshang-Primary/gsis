## One first party transport secret

Use the exact configuration name GSIS_SECRET across GSiS first party APIs. The user chooses the value outside code. Accept exactly 32 printable ASCII characters excluding whitespace. Never embed a production key in source, a browser asset, documentation, diagnostics or an archive.

If GSIS_SECRET is absent, preserve current legacy configuration behaviour. If configured, validate it and use it exclusively for the relevant first party transport; invalid configuration fails closed with a safe configuration error. Existing action scopes, replay protection and user authorisation remain.

Google OAuth, Meta credentials, Cloudflare Access, session signing and private link/token signing are distinct purposes and retain their required credentials. Sharing one first party key increases the number of services affected if that key leaks. State this once in setup guidance without adding an approval ceremony.
