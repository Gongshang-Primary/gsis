GSiS WhatsApp Messages

Every Roster WhatsApp message, who receives it and what triggers it. Generated from the template contracts and the Roster code on main, 6 Nov 2026.

Rules that apply to every message

  • Master switch: nothing sends unless WHATSAPP_ENABLED is true on gsis-roster-notifications. Each message type also has its own on/off in the activation settings.
  • Quiet hours 21:30–05:45: scheduled and routine messages wait. Explicit SMC actions (Let teachers see / Send WhatsApp), emergency absences and urgent forwards still go out.
  • Checked again just before sending: still current (not cancelled, superseded or expired), recipient active with a valid mobile, template approved by Meta with the exact wording. Otherwise it is dropped with a reason.
  • No duplicates: each message has a key; repeating an action does not resend what was already sent for the same content.
  • Private links: teacher messages carry a personal link (or a button) to their own duties; acknowledging in that page cancels pending reminders.
Source: notification-worker/template-contracts.json, templates.activation.json, shared/roster-operations.js. Status "On" = enabled in activation settings; Meta approval and the master switch still apply.
