# GSiS change workflow

Effective 25 October 2026, Singapore time, by the user's instruction.

A request labelled **changelog** authorises implementation, appropriate verification and a Git commit. Do not leave a confirmed fix as a queued note waiting for another commit instruction. A commit does not imply a live deployment, a remote push, or sending production messages.

Maintain the separate **GSiS Product Backlog** outside the source repository. Backlog items are proposals only. Do not implement, include in a release or commit their contents unless the user explicitly promotes them. Editing and saving the backlog is not authorisation to ship its items.

Record current requests separately from historical queue records. Preserve earlier release evidence and do not silently reimplement old entries. For substantial new products, resolve consequential product rules and make the design reviewable before implementation.
