# Roster 0.9.3a implementation and review plan

Scope: immediate Report Absence form and full-day shortcut; local dated timetable use; deferred Own arrangements drafts; pending peer requests in Assign Relief. Based on v0.9.3 (74dee29244ace62385c083173f62f0c34252f656).

## Confirmed causes

- Report Absence date changes waited for a compact report before hydrating the preloaded model. The home preload did not eliminate Calendar/report work. The reported 26-second production duration has not been reproduced locally.
- Own arrangements invoked saveAbsence/saveInstructions before opening its usable chooser.
- A pending dated network read took precedence over an available IndexedDB model on one localTimetable path.
- The no-instructions flag was cleared for newly saved full-day absences with unresolved timetable timing.

## Changes and invariants

1. Read verified form metadata without timetable/Calendar dependencies; render editable fields immediately. Full-day shortcut sends semantic coverage and explicit no-instructions through the existing authoritative write transaction.
2. Reuse only dated Calendar context, immutable model identity, verified teacher mappings and matching suspended timetable source. Do not infer tomorrow's parity from today's. Return cached rows before remote verification; guard owner/date/generation/source before applying replies.
3. Reuse existing signed Calendar proofs for read-only report requests. Preserve expiry, source age, owner/window checks and fresh mutation validation.
4. Keep draft instructions and colleague requests local. Submit absence validates and commits the batch together. Existing saved absences retain an explicit request submission action.
5. Return durable receipts before rebuilding report lists. Preserve uncertain-command identity, accepted replay and explicit server-denial handling.
6. Show peer-approval status distinctly from accepted cover in Assign Relief. Pending, rejected, expired and accepted states must not be conflated.

## Verification

Use real domain code and browser controls with externally held responses. Cover cold form, full-day semantic payload, dated cached projection, unchanged-source DOM retention, date/account races, source changes, draft no-write behavior, atomic validation, receipt replay, pending approval display, mobile layout and accessibility. Run current regression gate after generated-source synchronization. Package only changed Roster dependencies and record exact source commit/hash. No live deployment or live staff notifications.
