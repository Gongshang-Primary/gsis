# v0.8.0 implementation plan

Baseline: v0.7.19 / 2a0fffc. Spec: GSiS_Queued_Changelog.md items 043–047 and item 045 clarification. User authorises implementation, local commit and complete package, not production deployment.

Global constraints: fresh authority and exact retry receipts; no permission caching; preserve existing stores, URLs, publication/privacy boundaries and historical data; no live messages or production changes. Maintain full suite delivery with all five frontends and three backends. Runtime dependencies are already installed.

Rulings: v0.8 means semantic version 0.8.0; Confirm remains allocation-only and Publish is ordinary-teacher release; advance publishing defaults Off; background draft batches are preferred to losing all work until Publish. Current scope does not include a speculative storage migration without production evidence.

## Task 1: narrow Stapler date reads
Worktree ../v080-dates. Implement a trusted dates-only Contacts projection, early backend metadata context, bounded request-local metadata simplification and independent Drive read batching where safe. Keep all revocation/coherent-read guards. Do not change UI or add a second authoritative dates index. Failing behavior tests first, regression verification, local commit.

Failing browser tests first, regression verification, local commit.

## Task 3: atomic relief batches and advance publish
Worktree ../v080-batch. Resolve pending state before publication/export/navigation. Add persisted Admin-only allowAdvancePublishing default false and server/UI enforcement, with no implicit early notifications. Failing domain/backend/browser tests first, regression verification, local commit.

## Task 4: date-aware Timetable viewer
Worktree ../v080-timetable. Show cached valid baseline immediately with an inline spinner; fetch a compact authorized published effective-day projection; preserve published source and full unchanged-teacher cells independently of Calendar where available. Never expose confirmed/private drafts. Use the dated result for viewing and exports, preserve selections and reject stale responses. Distinguish not-requested/loading/unavailable Calendar; fix actual diagnostic timings. Failing domain/browser/gateway tests first, regression verification, local commit.

## Task 5: integrate and verify
Cherry-pick isolated task commits, resolve shared dispatch/shared model conflicts deliberately, regenerate canonical bundled copies. Review all four task diffs for spec and quality. Run the full suite once on the integrated tree plus package integrity. Run independent Thermonuclear correctness and quality passes against the same fixed baseline; apply Vercel/Ponytail/Pstack/Superpowers during integration and verification. Fix material findings and rerun affected checks.

## Task 6: release
Version all delivered runtime items 0.8.0, update deployment guide/change/API/performance scope and actual verification evidence. Build full package and minimal installation artifacts. Commit/tag release, build repository bundle, rebuild final package with exact commit identity, verify hashes/content and save deliverables. No remote push or live deployment.
