# GSiS v0.5.04

Implements Q144–Q149 following the user's commit instruction. Baseline: v0.5.03, commit `3f024cb6d2d940d3da8a61e79ba6a63f0a94bb20`. Write protocol remains 500.

- **Contacts correctness (Q144):** degraded viewing snapshots are explicitly non-authoritative and cannot remove staff through a Deploy import. The original journal is durable before its pending pointer is published. Viewing fallback also handles journal-read failures. Account changes clear personal caches; stale authentication failures cannot expire a newer session. DIY drafts and immutable pending requests survive navigation. Unavailable teaching data blocks dependent FT filters and export. Save and publication approval share alias validation. Recalculate preserves backup/history formulas and touches only its intended operational fields.
- **Contacts diagnostics and transport (Q144):** service errors expose a sanitized category, operation, phase and reference. The read-only editor helper `inspectContactsWriteAccess504()` reports the actual executing account and exact planned write ranges, including IDs and commit markers. Cold-read and receipt deadlines now fit their gateway budgets; response-body reading remains inside the deadline, partial-budget retries are avoided, and earlier failure references survive later attempts. These changes do not establish production latency.
- **Immediate FT guard (Q145):** assigning a teacher to a second form class is rejected in the current draft, with the existing class identified. Stable teacher IDs and unsaved assignments are checked; the backend guard remains.
- **Committee leadership (Q146):** committees have optional HOD i/c, SH i/c, OIC and 2IC rows before Members. Existing members remain members. Ambiguous old Head/Deputy occupants remain visibly retained under their old labels until an editor selects a specific role, moves them to Members or removes them; no appointment is guessed.
- **Formula typography (Q147):** rendered formula scale is aligned with surrounding text, with natural vertical space for fractions. Calculations are unchanged.
- **Explicit role offloads (Q148):** an explicit role percentage replaces its general appointment percentage. HOD SM starts at an ordinary editable/deletable 50% entry. Future roles can be added from the maintained HR catalogue. Zero is an explicit override; blank/deleted uses the general rate. A migration marker preserves edits and deletion. Independent employment adjustments and weekly caps remain. The Offload table also remains editable after a confirmed save; the soft-refresh toolbar wrapper mismatch is corrected.
- **Suite I/O (Q149):** narrow Deploy saves read their validated root dependencies and maintain per-root indexes. Duplicate saves confirm their existing journal before loading the draft. Unnecessary read flushes, broad Offload audit values and repeated response serialization are removed. Layout skips snapshot payload reads for a verified unchanged cursor and patches only dirty editable-table rows. Shared value-service counters, focused probes and a static I/O inventory provide reviewable evidence.
