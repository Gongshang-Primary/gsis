# GSiS v0.4.15

Authorized by “commit next ver” on 30 September 2026. Prepared release; no live installation or publication.

- Q97: specialist subjects default to PE, Art, Music and TL and remain selectable. Pools use active eligible teachers assigned the main subject, independently of TTb modifiers. Demand counts distinct active co-teachers, with a minimum of one for an unstaffed class/TG. TL demand includes TL, HTL and TGs named CCE TL, using their own weekly loads; the pool uses TL teachers.
- The individual specialist target is FTT allowance + retained fraction × demand / specialist headcount. The separate pool reference retains demand / retained capacity + FTT. Other subjects increase actual workload; multiple specialist targets stay separate. School-wide quota/status, PD, duties, exact caps and rounding are preserved. Teacher definitions flag missing PE/Art/Music modifiers, and IP Deploy flags retained inactive assignments.
- Q98: Contacts My signature downloads a 900 × 180 PNG using the supplied artwork, Statutory Name as stored, Outfit Bold in the artwork’s blue, and Outfit Regular designation in black. Designations use formal appointed role names or published teaching subjects; ordinary-teacher fallback is Teacher. Each text line fits its available width. Admin Signature settings selects the school-wide subject list; defaults are the ten agreed subjects in full names.
- Q99: historical saved-value notices now say Saved values changed. Acknowledge persists per signed-in editor, version and audit event. Later defers the prompt. Failed acknowledgement stays actionable; audit history and deployment values are retained. Notices wait for an existing dialog to close.

Suite v0.4.15; Deploy write protocol 415. Existing Sheets API service, recovery flows, URLs, secrets, session settings and school data remain compatible. This release does not change 2D/3D geometry.
