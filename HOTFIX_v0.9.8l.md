# Install GSiS 0.9.8l

Focused Roster, Calendar and Deploy patch on K. Read `SETUP.md` or `SETUP.html` first.

1. Install the matched Roster backend and Pages frontend L files into the existing projects.
2. Install the matched Calendar backend and Pages frontend L files into the existing projects.
3. Install the matched Deploy backend and Pages frontend L files into the existing projects.

Save copies of the current deployed versions first. For each Apps Script backend, save the code and deploy a new version of its existing web app. Preserve its `/exec` URL and Script Properties. Saving editor code alone does not update production. Keep all Pages environment variables, bindings and domains.

The notification and private Operations Worker files are optional parity updates only where already deployed. No new Worker, D1, R2, Queue, authority switch, key or cron is needed. The separate I rehearsal remains unchanged.

Auto-allocate now reoptimises eligible unpublished automatic drafts within the existing window ending 06:29 Singapore time. Auto-fill blanks preserves current assignments and fills gaps at any time. K's suspended-day rules stay active. Calendar uses native spreadsheet IO. Resolve all local undefined class rows before saving a Deploy rename batch.

Use `PATCH.json`, `SHA256SUMS.txt` and `VALIDATION.md` to check the package. Source/history files are for maintenance, not Pages upload. Keep the actual backed-up matched deployment files for rollback and preserve current school data. Source baseline K includes J Calendar/Deploy components; the installed school copies may be older.
