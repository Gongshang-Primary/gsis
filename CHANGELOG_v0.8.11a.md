# GSiS v0.8.11a

23 October 2026. Deploy frontend patch based on v0.8.11.

1. Adds the requested `|` between ASC Export and Audit. ASC Export remains available to KP and Admin users; Audit remains Admin only.
2. Restores vertical page scrolling on ASC Export. Its form tables no longer lock the document as a single table view. Long mapping tables retain their own scrollbars and scrolling continues down the page when a table reaches its end.

Install `Deploy_Frontend_v0.8.11a.zip` in the existing Deploy Pages project. All other components remain at v0.8.11. No Apps Script, API, Script Property or data migration changes. No live deployment was performed.
